3. เผยแพร่บน GitHub

ปลายทาง: kasemsuk1499-svg/AUTOCHEST · main — บันทึกไฟล์ภาพและค่าตั้งต้นใน commit เดียว ไม่แก้ไขสกิลหรือค่าสเตตัส

ใช้ Fine-grained personal access token ที่จำกัดเฉพาะ Repo นี้ โดยให้สิทธิ์ Repository permissions → Contents: Read and write เท่านั้น ตั้งวันหมดอายุสั้น ๆ ไม่ต้องส่ง Token ในแชท

Token ส่งตรงไปยัง api.github.com ผ่าน HTTPS เท่านั้น ไม่เก็บลงไฟล์, localStorage หรือ sessionStorage ผู้ไม่มีสิทธิ์เขียน Repo จะเผยแพร่ไม่ได้ หน้านี้เป็นเครื่องมือสาธารณะที่ไม่ซ่อน URL แต่การเขียนต้องผ่านการตรวจสิทธิ์ของ GitHub
