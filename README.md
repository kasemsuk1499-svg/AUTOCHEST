# AUTOCHEST 🎮

เกม **Auto Chess / Auto Battler** แบบ 2D Chibi เล่นผ่านเว็บด้วย HTML5 Canvas และ JavaScript โดยไม่ต้องมีเซิร์ฟเวอร์

## เล่นเกม

- เปิด `index.html` ด้วย Chrome หรือ Edge หรือเผยแพร่ผ่าน GitHub Pages
- ซื้อฮีโร่จากร้านค้า แล้วเลือกยูนิตจากม้านั่งเพื่อวางในสนาม **ฝั่งสีน้ำเงินด้านล่าง**
- กด **เริ่มต่อสู้**: ยูนิตจะเดินหาเป้าหมาย โจมตี และใช้สกิลเอง
- ซื้อยูนิตชนิดเดียวกัน **3 ตัวเพื่อรวมเป็น 2 ดาว**; รวมต่อเป็น 3 ดาวได้
- รีโรลร้านค้า 2 Gold, เร่งการต่อสู้ x2, และสู้บอสทุก **3 เวฟ**

## ระบบที่มีใน v0.1

- สนาม 6 คอลัมน์ × 7 แถว, วางทีมได้เฉพาะ 3 แถวล่าง
- ฮีโร่ 7 ประเภท: อัศวิน, จอมเวท, มือปืน, ผู้พิทักษ์, นินจา, เทพสายฟ้า, ขุนค้อน
- HP, ดาเมจ, ระยะ, ความเร็วโจมตี, AI เลือกเป้าหมาย, สกิลพิเศษ, เอฟเฟกต์, ตัวเลขดาเมจ
- ร้านค้า, Gold, ม้านั่งสำรอง, รวมดาว, โบนัสสายอาชีพ
- ความยากตามเวฟ, บอสทุก 3 เวฟ, สรุปผลต่อสู้ และการได้รับ Gold
- รองรับหน้าจอคอมพิวเตอร์และมือถือ (responsive)

## โครงสร้างไฟล์

```
index.html         หน้าเกม
src/styles.css     ธีมและเลย์เอาต์
src/game.js        ระบบจัดทีม, เศรษฐกิจ, ต่อสู้, AI, เอฟเฟกต์, UI
README.md          วิธีเล่นและแผนพัฒนา
docs/GAME_DESIGN.md กติกาและแผนพัฒนาระบบ
```

## แผนพัฒนาต่อ

1. แยกไฟล์ข้อมูลฮีโร่, combat engine, UI renderer ให้เป็นโมดูล
2. ปรับภาพตัวละครเป็น sprite/PNG แยกไฟล์ เพื่อลดภาระ Canvas และเพิ่มแอนิเมชัน
3. เพิ่มระบบ XP / Level, ไอเทม, อัตราดรอป, synergy แบบหลายระดับ และ economy ที่สมดุล
4. เพิ่มระบบเซฟ localStorage, หน้าคอลเลกชันฮีโร่ และการทดสอบสมดุลเกม
5. เพิ่มโหมด PvE และ PvP หลังระบบต่อสู้เสถียร

> สถานะ: **Playable Alpha** เป็นเกมเล่นคนเดียวฝั่งเบราว์เซอร์ ยังไม่มี backend/PvP หรือระบบเซฟถาวร
